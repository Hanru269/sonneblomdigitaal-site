Why a city?

I run lots of small things at once: an Etsy shop, digital downloads on Gumroad, books on Amazon, social pages, an AI influencer, a few small bots. Checking 10 websites every morning got old, so I asked Claude to pull everything into one place and make it fun to look at. Now I open one link on my phone and see everything.

How it works

1 · Shops & platformsEtsy, Gumroad, Printify, Facebook/Instagram, GitHub, Apify, the Solana blockchain…
↓
2 · Collector script (Python)Every 30 minutes a small server asks each platform's API for the latest numbers and saves one snapshot file.
↓
3 · Lock it upThe snapshot is encrypted (AES-256, the same kind banks use), so only someone with the password can read it.
↓
4 · Free hostingThe encrypted file and the city's code are pushed to GitHub Pages: free hosting, nothing to maintain.
↓
5 · Your browser builds the cityOn your phone the password unlocks the data, and Three.js (a 3D library) builds the city: buildings, cars, people, rain, neon.

The private numbers are never visible on the internet. The website only ever holds a locked file.

A peek at the code

Each building is one small block of settings. Adding a new business means adding one of these:

// one building = one side hustle
{ id: "etsy", name: "Etsy Megastore", icon: "🛍️",
  color: 0xff8a3d, pos: [-25, 6], h: 11, kind: "market",
  board: { title: "ETSY MEGASTORE", main: views,
           rows: [["Orders", orders], ["Favourites", favs]] } }

The collector is just as simple: one small function per platform.

def github():
    """Repos and commits pushed today, from the GitHub API."""
    repos = gh("/user/repos")
    events = gh("/users/me/events")
    return {"repos": len(repos), "commits_24h": count_pushes(events, hours=24)}

And this is how the browser unlocks the data with the password:

Build your own with Claude

  1. Get Claude Code (claude.com/claude-code) on a computer or a cheap cloud server (Linux, about $5 a month).
  2. Create API keys: Etsy (developer account → app), Gumroad (Settings → Advanced → Application), and a free GitHub account.
  3. Give Claude the prompt below, then add one building at a time.
  4. Ask Claude to set up a schedule (cron) so the numbers refresh every 30 minutes.
  5. Open the link on your phone and tap "Add to Home Screen". It works like an app.
“Build me a private dashboard for my Etsy shop and Gumroad store. Write a Python script that pulls my listings, views and sales from the Etsy and Gumroad APIs every 30 minutes, encrypts the result with a password, and publishes it to GitHub Pages. Then build a page with Three.js that unlocks the data in the browser and shows each shop as a glowing 3D building with a billboard of its numbers. Start simple with Etsy, show me a screenshot, then we'll add more.”

Tip: go step by step. Ask for one building, check it on your phone, then ask for the next one. Claude remembers how everything fits together.
