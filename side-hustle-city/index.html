Questions

Will this make me money?

No, and we won't pretend it will. It's a dashboard. It helped us notice which hustle was dead weight and which one deserved more time. That's the whole pitch.

What do I need?

Accounts for the hustles you want in the city: Etsy, Gumroad, Amazon KDP, Shopify, Facebook/Instagram, and so on. For the Full System plan you also need a Claude subscription (or another AI coding assistant) and a computer or small cloud server to run it on. Hosted and Done For You need nothing extra.

Is my data private?

Yes. Your numbers are encrypted (AES-256) before they're put online, and only your password unlocks them in your browser. The public website only ever holds a locked file. We ask for read-only access wherever a platform offers it.

Which platforms work?

Anything with an API (Etsy, Gumroad, Printify, Facebook, Instagram, GitHub, Stripe, crypto wallets…) plus manual numbers for places without one, like Amazon KDP.

Are the numbers in the video real?

No. The video and the live demo use sample numbers only.

Does it work on my phone?

Yes, it was built phone-first. Tap buildings, pinch to zoom, use the joystick in Street mode.
